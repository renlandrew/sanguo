# 首领法术 Effekseer 贴图（10-27）

用户：「所有这些效果，你可以通过unity effeser，加gpt image 达成吗」→「Rebuild the boss spells with Effekseer plus GPT textures」。
Veo 黑底录像抠出来带一层灰雾，叠到场景上成一块发亮的长方形（用户：「不行，有明显的正方形」），所以改成 Effekseer 渲染（纯黑底、边缘干净），把官方样例里的贴图换成 GPT 画的。
贴图都是白色／浅灰画在纯黑底上（Effekseer 按参数上色，游戏里再按首领主色换色阶），排版和被替换的原贴图一样。

## tex_bolt（替换 MAGICALxSPIRAL Texture/Thunder2.png，张角天雷）
```text
素材键名：tex_bolt；画幅比例：1:1。特效贴图，不是插画。
画面：纯黑底上 8 道白色闪电，排成 2 列 4 行，每格一道，每道横向贯穿整个格子（从格子左边缘到右边缘）。
形状：每道闪电是一条粗细有变化的主干，折线像真实闪电那样不规则拐 5–8 次，带 1–2 根短分叉；主干中心纯白、边上一圈柔和的淡蓝白光晕。8 道彼此形状都不同。
画风：手绘笔触的亮光，干净大方。
排除：不要文字、符号；不要背景纹理、云、地面；不要小碎点、星星、密集细丝；格子之间不画线，闪电不跨格。
```

## tex_flame（替换 tktk02 Parts/Fire.png，华雄地火、吕布火龙）
```text
素材键名：tex_flame；画幅比例：1:1。特效贴图，不是插画。
画面：纯黑底上 4 团白色火焰，排成 2×2，每格一团，火焰底部在格子下缘、尖端朝上，占格子高度的八成。
形状：每团是几条大火舌往上卷，边缘柔和、内部有浅灰明暗层次，像水墨里的大笔火焰但是纯白发光；4 团形状各不相同。
画风：手绘大笔触，大块面，简洁。
排除：不要颜色（只要白和灰）；不要文字；不要火星、小碎点、密集细线、烟雾颗粒；不画格子线，火焰不跨格。
```

## tex_firefield（替换 tktk02 Parts/Fire6.png，李傕烟火、吕布）
```text
素材键名：tex_firefield；画幅比例：1:1。特效贴图，可四方连续。
画面：一整片翻卷的火焰与烟的明暗图，白色是最亮的火，灰色是烟，黑色是空隙；大团块，最多十来个主要团块。
画风：大笔触的手绘，块面大、边缘柔和。
排除：不要颜色；不要文字；不要小碎点、颗粒噪点、密集纹理（不要密集恐怖症那种斑点）。
```

## tex_slash（替换 tktk02 Parts/Line6.png，胡轸双刀、李傕横刀）
```text
素材键名：tex_slash；画幅比例：1:2 竖版。特效贴图。
画面：纯黑底正中一道竖直的白色刀光，两头尖、中间最宽（约画面宽度的四分之一），像一笔毛笔一扫而过：一侧边缘锐利、另一侧带两三缕飞白的笔丝。
画风：手绘大笔触，中心纯白，外缘柔和渐暗。
排除：不要颜色；不要文字；不要兵器本体；不要小碎点；不要直尺般的直边，要有笔触的轻微弯和粗细变化。
```
