# 敌人立体化（去「纸片感」）流程

10-28 用户：「这些黄巾军感觉有点像纸片，尤其是骑兵，需要重新用 meshy 做一次吗」「先把流程脚本和要求整理好」。

## 先搞清楚现状

| 兵种 | 现在怎么做的 | 为什么像纸片 |
|---|---|---|
| 步兵（黄巾兵、力士、弓手、术士、西凉兵、飞熊军、陷阵营、百姓、程远志） | 已经是 Meshy 建模 + 绑骨 + 动作库，Blender 渲成 8 帧（`工具/render_v2.sh`） | 渲染用的是 Workbench 平涂（只有贴图颜色，没有真正的光影）+ 描边 + 调鲜，侧面一片平；256 像素、8 帧 |
| 骑兵（黄巾骑兵、西凉铁骑、弓骑、狼骑） | Veo 视频切帧（`工具/veo/make_foe_pack.py`） | 视频本身就是一个角度的平面画，没有体积 |

所以步兵**不用重新建模**，先换渲染方式；骑兵才需要重做。

## 第一步：步兵换真光照（不花 Meshy 点数）

`工具/blender/render_frames.py` 加了 `light=lit`：Eevee 真光照——左上暖色主光、背后冷色轮廓光（勾出边）、天光补暗面、环境光遮蔽、软阴影，不描边。可调 `key=3.2 rim=2.4 amb=.6`。

1. 出对比图：`bash 工具/test_lit.sh 黄巾兵` → `美术/对比_立体化_黄巾兵.png`（A 现在 / B 真光照 / C 真光照大一号）。
2. 看对比图挑一种；如果选 B 或 C，把 `工具/render_v2.sh` 里的 `light=studio` 换成 `light=lit`（选 C 再把 `size=256` 改 384），`ink_post.py` 的 `vivid=1.25` 可能要调小（真光照本身够鲜），跑 `bash 工具/render_v2.sh` 全部重渲。
3. 云端没有 Blender 和模型文件（glb 没进仓库），这一步只能在本机跑；`light=lit` 是在云端写的、没实际跑过，第一次跑如果报错把报错贴回来。

## 第二步：骑兵重做（花 Meshy 点数，先试一个）

难点：**Meshy 的自动绑骨和动作库只支持人形**，马绑不了，不能照步兵那套「绑骨 → 套跑步动作」。

建议路线（先试黄巾骑兵）：
1. 画三视图：提示词在 `工具/画图/jobs_qibing3v.json`（人马一体、标准站姿、中灰底三格）。用 `OUT=美术/黄巾骑兵/v2 JOBS=工具/画图/jobs_qibing3v.json bash 工具/画图/codex_draw.sh`，画好改名成 `美术/黄巾骑兵/v2/三视图.jpg`。
2. 只建模不绑骨：`python3 工具/split_turn.py 美术/黄巾骑兵/v2/三视图.jpg 美术/黄巾骑兵/v2`，再 `MESHY_KEY=… python3 工具/meshy.py multi 正面.png 侧面.png 背面.png` 和 `wait multi-image-to-3d`（约 20 点）。
3. 渲染：静止模型用真光照渲，跑动靠程序做——身子上下起伏、前后点头、扬尘，腿不动。先看这样够不够「立体」。
4. 如果腿不动不能接受，再考虑：Blender 里给马手工绑四足骨（Rigify 有马的模板）做一段奔跑循环，这要人手做，工作量大很多。

## 验收标准

- 手机上看，敌人有明显的明暗面和轮廓光，侧面不再是一片平。
- 跑动时身体有体积感（转身、起伏能看出厚度）。
- 颜色风格和武将立绘、战场底图不打架（不要太暗、太写实）。
- 一张图集仍控制在 4096 以内，帧数不少于现在。
