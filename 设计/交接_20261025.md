## 二、怎么跑

- **起服务：** 本地静态服务是 `.claude/launch.json` 里的 `sanguo`（8766 端口，根目录 `三国志/`）。
- **打开：** `http://localhost:8766/原型/守关.html?all`（`?all` 跳关试玩：全关解锁，等级、强化低于推荐的按推荐补上）。
  - 直接打开磁盘文件会读不到旁边的图和脚本，整页发黑。
- **测试另开一套档：** `?save=名字`，例如 `?save=t1`，写到 `sgz.t1.*`，不碰玩家真存档。
  - 测完删掉：`for (const k of Object.keys(localStorage)) if (/^sgz\.t\d+\./.test(k)) localStorage.removeItem(k)`。
- **玩家真存档（不能覆盖）：** `sgz.proto.stars`、`sgz.proto.roster`、`sgz.proto.inv`、`sgz.proto.daily`。
  - 10-25 夜的星数是 `{"1":3,"2":3,"3":2,"4":2,"5":1,"6":3,"7":2,"10":2,"30":2}`。
  - 武将经验是用户自己打关涨的，不是测试改的。
- **调试接口 `window.__sg`：**
  - **跑关：**
    - `start(i)` 开第 i 关（从 0 数）；`open(i)` 走出阵或门槛流程。
    - `step(n)` 推 n 帧；`draw()` 手动画一帧（面板藏着时浏览器不跑动画帧）。
    - `turbo = 0` 停住；`auto = true` 机器人替玩家点。
    - `G` 是当前一局；`scr` 读写当前页面（`menu` / `camp` / `armory` / `counsel` / `roster`）。
  - **推演：**
    - `sim(i, maxT)` 跑一局；`bench(关序号数组, 种子数)` 返回字符串，要用 `String()` 包。
    - `seed` 设种子。
    - `noUp = true` 机器人不带强化（看门槛卡不卡得住）。
    - `advTest(关数组, 种子数)` 看三位军师荐错率。
  - **存档、物品、每日：**
    - `inv`、`daily` 读物品和每日记录；`dayOff = 2` 假装过了两天（测点卯补领）。
    - `tick()` 手动触发每日结算；`gateLack(id)` 查第 id 关还缺哪些门槛；`nextGate()` 查下一道没过的门。
  - **表现：**
    - `ult('guan')` 播大招特写；`ml` 拿两层墨流（`[ML, MLB]`）。
    - `forceC = 'luzhi'` 临时换军师。
- **后台跑推演的坑：**
  - 后台标签页的 `setTimeout` 被节流，长任务用 `MessageChannel` 让步。
  - 30 关 × 6 种子的调血量循环约 5–6 分钟，写法见 `方案初稿.md` 历次「重调」。
  - 单次 JS 调用超过 45 秒会超时，要分段轮询。

## 三、用户偏好和硬规矩（务必遵守）

- **说话：** 用简体中文，短，结论先说。
- **特效主体必须是画稿：**
  - 剑气、刀气、裂缝、光都用 ChatGPT 画，代码只管飞、缩放、闪、显露。
  - 不许拿代码画平行光条、梭形、规则圆环、一团径向光当主体。用户原话：「不要这种几何图形啊都不像游戏」「好丑」。
  - 纸色地面上叠加发光（`lighter`）会冲成白雾，要用正常叠色。
- **不要密集图案：** 不要一堆小点、小碎片、鳞片；简笔、大色块。
- **界面不要「像网页」：**
  - 纯文字行、药丸框、代码画的框都被说过「太 HTML」。
  - 用画的件：乌漆面细金边（`ui2_*`）、牌匾（`ui_plaque_*`）、古印（`uiSeal`）、圆钮（`roundBtn`）、物品图标。
  - 按钮不要繁杂，元素不要堆在一起。
- **法术横幅只写招名，** 不要下面那行解释。
- **竖排招名：** 衬第一版剑形旗带（`img/skb_<人>.png`，原图 `美术/界面/招名剑形旗带.jpg`），字必须整列落在旗带实心那段里、不许超出边（现在 16 号字、旗带宽 32）。不要换回更宽的重画版。
- **美术要分得开：** 每类单位各有主色、剪影、大小、兵器。
- **人物主色：** 关羽青（青金、玉色）、张飞火红、刘备蓝／金。
- **只改画面的改动，** 改完跑 `bench` 证明星数一字不差；改了玩法要重调血量。
- **画面随机数：** 只能用 `VR()` / `vr()`，不能用游戏随机数 `R()` / `rnd`，否则推演结果会变。
- **注释坑（这次踩了两回，整页黑屏）：**
  - 不要在一行代码中间插 `// 注释`，后面的代码会被吞掉；行中间的说明用 `/* */`。
  - 改完用 `new Function(脚本)` 查一遍语法：取页面里最大那段 `<script>` 文本。
- **花钱、授权：**
  - 花钱要先问。
  - 不替用户点 OAuth 授权：Cloud Shell 的「授权」要用户自己点。
  - 不改生产服务器、不改 `~/.ssh/config`。
  - Meshy 的 key 不写进项目文件。
- **技能：** 法术相关改动先看项目技能 `sanguo-spell-fx`（`.claude/skills/sanguo-spell-fx/SKILL.md`）。
- **记忆：** `~/.claude/projects/-Volumes-andrew-s-SSD-Downloads-mindstone-game/memory/` 里有偏好记忆，含今天新加的 `no-geometric-fx.md`。
